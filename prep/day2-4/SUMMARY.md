## Что нашла репетиция (главное)

1. **Сеть — главный пожиратель времени.**
   - Прокси даёт 20–40 КБ/с и рвёт соединения.
   - Демону Docker Hub недоступен напрямую.
   - Сколько ушло на загрузки: NuGet (51 МБ) — 10 мин; Python-колёса для заглушки (31 МБ) — 35 мин; npm — больше часа, и фронт так и не собрался. pandas и lightgbm к концу этапа ещё не скачались.
   - **Вывод:** офлайн-запас (wheels, NuGet, npm, `docker save` базовых образов) делается заранее и приносится с собой. Это задача номер один на дни 5–6.
2. **Корпоративные конфиги ломают «голую» машину.** Глобальный `NuGet.config` указывал на недоступный фид. Решение: в шаблоне свой `nuget.config` с `<clear/>`. Для pip и npm проверять так же.
3. **Версии, закреплённые вслепую, не совпадают со скачанными** (fastapi 0.115 против 0.143, numpy 2.1 против 2.4). Правило: версии закрепляются по содержимому `offline/`.
4. **Тяжёлые инструменты не берём.** Из-за orval установка npm растянулась больше чем на час. Клиент API написан руками по контракту за минуты.
5. **FK в схеме замедлял импорт в 5 раз** (106 с → 22 с). На время COPY ключ снимаем.
6. Мой собственный ложный вывод: «Docker Hub доступен», потому что `hello-world` уже лежал локально. Доступ проверяем через `check-network.sh` (доступность **и** скорость), а не одной командой.

## Решения по вопросам к контракту

| Вопрос | Решение |
| --- | --- |
| FK при импорте | Снимаем на время COPY; ML не читает данные во время импорта |
| `test.csv` поверх `train.csv` | Не затирать известные `sales` значением `null` (COALESCE) |
| `interval_level real` | Перевести на `numeric(3,2)` |
| ML: `interval` ≠ 0.8, 503 при недоступной БД, `cv_metrics` зависят от `cutoff_date` | Принять и обновить `ml-api.yaml` |
| ML: агрегат и `warnings` считаются по всему датасету, а не по запрошенным `series_keys` | Баг ML, исправить. На API не влияет: API всегда просит все ряды |
| Фронт: дни без продаж | В `train.csv` это 0, пропусков дат нет, кроме 25 декабря; `sales` в истории не nullable |
| Фронт: `/api/health` → 503 | Мок только при таймауте или сетевой ошибке; на 503 показывать «API без БД» |
| Фронт: прогоны из других вкладок, активный импорт после перезагрузки, `horizon` < 16 | Отложено на день 2 хакатона, для заглушки не нужно |
